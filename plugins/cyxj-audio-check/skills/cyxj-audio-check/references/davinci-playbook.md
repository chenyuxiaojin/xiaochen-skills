# 达芬奇音频修法手册(大白话版)

给不懂音频的人看的。先看「放行标准」知道数字要到哪,再按「病因对照」找自己那一条,照「修法」点菜单。
菜单名按 DaVinci Resolve Studio 21 中文界面写(2026-09-04 实机核对)。

## 0. 四个数字是什么(只需要懂这四个)

| 名字 | 大白话 | 目标 |
|---|---|---|
| 响度(LUFS / LKFS) | 整段平均起来有多响,平台就看这个 | -14(YouTube / 抖音 / B 站通用) |
| 真峰值(dBTP) | 全片最响的那一瞬间;数字音频有绝对天花板 0,碰到就破音 | ≤ -1 |
| 左右声道差 | 两只耳朵听到的是不是一样响 | ≤ 1 dB |
| BGM 比人声低多少 | 音乐衬底还是抢戏 | 15 ~ 20 dB |

一句话记住:**响度决定观众要不要调音量,峰值决定会不会破音,声道决定耳机听着偏不偏,BGM 比例决定音乐吵不吵。**

平台只往下压音量、不往上抬:-20 LUFS 的片发出去就是比别人小声,没人替你救。

## 1. 放行标准(体检脚本就是照这个判的)

| 项目 | ✅ 可发 | ❌ 不可发 |
|---|---|---|
| 整片响度 | -16 ~ -12 LUFS | < -16(太轻) |
| 真峰值 | ≤ -1 dBTP,无削波 | > -1 或有削波(会破音) |
| 左右声道 | RMS 差 ≤ 1.5 dB | 差 > 1.5 dB(人声偏一边) |
| BGM / 人声 | 低 15 ~ 20 dB | 低 < 12 dB(BGM 太大) |
| 片中静音 | 无 > 1.5 秒空白 | 有(确认是不是漏音) |
| 视频码率 | 4K30 ≥ 35 Mbps,1080p ≥ 8 Mbps | 低于下限 |
| 音频编码 | AAC ≥ 192 kbps,48 kHz | < 128 kbps |

## 2. 病因对照(你听到的 → 数字上是什么 → 修法编号)

| 你的感觉 | 数字上 | 通常原因 | 修法 |
|---|---|---|---|
| 人声太小,别人视频都比我响 | 响度 < -16 | 音频助手母带没落到成片 / 推子被拉低 / 「归一化至标准」撞峰停了 | F2 |
| 拖回达芬奇表全红 | 峰值 -1 ~ -3,削波 0 | **不是问题**,-14 标准的成片峰值就在这里,红 = 接近上限不是破音 | 不用修 |
| 有破音、刺耳 | 峰值 > -1 或削波系数 > 0 | 推子推过头 / 归一化没限峰 | F3 |
| 戴耳机人声偏一边 | 左右差 > 1.5 dB | 录音源只进了一个声道(话筒接在单边) | F1 |
| BGM 太吵,盖住人声 | BGM 只低 < 12 dB | 音乐轨没闪避 / 电平设错 | F4 |
| 一会大一会小 | LRA 大、短时响度乱跳 | 对白没拉平 | F5 |
| 音频助手选了 YouTube 还是小声 | 响度 -25 ~ -30 | 助手跑得太早被后续改动冲掉,或母带效果挂的总线没被交付 | F2 + 第 4 节 |

## 3. 修法(照着点)

### F1 声道:人声只在一边

1. 编辑页时间线上选中**全部**人声片段(剪过的每一段都要选)。
2. 右键 → 「片段属性…」(⌥L)→ 顶上切到「音频」页。
3. 「格式」改 **Mono**;「源声道」选实际有声音的那个:内嵌通道 1 = 左,内嵌通道 2 = 右。体检报告会告诉你哪边响。
4. 确定。左右就平了。

根治:录音时把话筒设成单声道,或录完先转单声道再进 Remotion / 达芬奇。

### F2 响度:整片太轻(最常用)

交付页 → 音频 → 「音频归一化」区:

1. 勾「归一化音频」。
2. 选 **「优化至标准」**(不是「归一化至标准」)。
3. 「标准」下拉选 **YouTube**,它会自动填 -14 LKFS / -1 dBTP。
4. 「输出轨道 1」保持勾选。导出。

为什么不用「归一化至标准」:它只推音量不压峰,最响的一瞬撞到 -1 就停,平均往往只到 -20 左右。「优化至标准」会先把最响的几个尖削平再整体抬,才能到 -14。

导出后**必须复测**(体检脚本或 Fairlight 响度表选 YouTube 看「整体」≈ -14)。

### F3 峰值 / 削波:破音

1. Fairlight 页把总线推子(Bus 1)降 3 dB,或把人声轨降 3 dB。
2. 再按 F2 用「优化至标准」导出——它自带限峰,会把峰值按在 -1 以下。
3. 如果源文件本身已经削波(波形平顶),回去重录或换母带,后期救不回来。

### F4 BGM 太大

1. Fairlight 页,音乐轨推子先拉到人声轨下方约 18 dB(人声推子 0,音乐 -18 起步)。
2. 要「人声一出音乐自动让路」:跑一次音频助手(见第 4 节),或在音乐轨挂 Ducker。
3. 按 F2 导出并复测,看「BGM / 人声」那行到 15 ~ 20 dB。

### F5 忽大忽小

1. 选中人声片段 → 右键「归一化音频电平…」→ 模式 ITU-R BS.1770-4 → 目标 -16 LUFS,先把每段拉平。
2. 再跑音频助手让它做对白拉平,最后按 F2 导出。

### F6 码率

交付页 → 视频 → 「质量」选「限制为」并手填:4K30 用 40000 Kb/s,1080p 用 12000 Kb/s;音频 AAC 320 Kb/s、48 kHz。

## 4. 音频助手(自动混音)怎么用才不翻车

它做的事:给轨道分类 → 拉平对白 → 让音乐给人声让路 → 按你选的标准挂母带效果。

规矩:
1. **所有素材全放好、剪辑全定稿之后,最后一步才跑。** 跑完再改剪辑,结果会被冲掉。
2. 标准选 YouTube。
3. 跑完立刻在 Fairlight 响度表(⋯ → YouTube)整片播一遍看「整体」。不到 -14 就别指望它,直接用 F2 兜底。
4. 交付页的「音频归一化 → 优化至标准 → YouTube」永远勾着,当保险。

2026-09-04 实战:助手选了 YouTube,导出实测只有 -29.7 LUFS,原因未明;交付页「优化至标准」一步到 -14.1。所以:**助手负责好听,交付页归一化负责达标,复测负责放行。**

## 5. 不想回达芬奇:ffmpeg 应急(画面原样拷贝,只重编码音轨)

```bash
# 已混好的成片:修声道 + 拉到 -14
python3 "${CLAUDE_PLUGIN_ROOT}/skills/cyxj-audio-check/audio_fix.py" remaster 成片.mp4 --mono-from right

# 人声 + BGM 重新混(自动闪避 + 拉到 -14),画面用原视频
python3 "${CLAUDE_PLUGIN_ROOT}/skills/cyxj-audio-check/audio_fix.py" mix --voice 人声.wav --bgm 音乐.mp3 --video 画面.mp4
```

跑完脚本会自动复测输出文件。局限:remaster 改不了已经混进去的 BGM 比例;要改比例只能 mix 重混或回达芬奇。

# 6 平台标题+简介规格(陈与小金)

主平台:YouTube / B站 / 抖音。分发平台:视频号 / TikTok / 小红书。
标题+简介**成对**交付。写完逐条自检:字数?有数字?主语是观众认识的东西?体裁匹配?是陈述句?

## 标题总则(2026-09-04 复盘后定稿)

**标题 = 东西名 + 体裁词 + 一个具体事件 + 一个数字判决。** 平铺直叙,像新闻导语。
依据:自家三平台高播放标题全部是这个结构(见文末样本);外部研究一致——
1of10(32.3 万条视频):约 30 字符标题中位播放最高,判决 / 冲突框架比说明型高 20%,数字只有作为判决时才加分;
AIR(18,080 频道 11 品类):30-50 字符是全品类甜区,科技区数字只有当"承诺 / 判决"才有效,ALL CAPS 在教育区负向;
B 站官方《UP主创作手册》:≤25 字,用户 2 秒决定,「热点 + 事件 + 类型 + 亮点 + 人物」至少 3 项,重点前置;
抖店学堂官方作者课:抖音标题是左下角文案,点击靠封面和前 3 秒,好标题要"逻辑 + 情绪"同时有。

字数按中文字计(英文工具名按实际字符,Claude Code 算 11)。

## YouTube(主)

- **标题 ≤25 字**。主语(工具 / 功能名)前置——既是判决的主语,也是搜索词。冒号后接事件 + 数字。
  工具名本身是英文的直接写一次(Claude Code / Agent Teams);全句用冒号 / 逗号分隔;大小写照常。
  体裁标记(实测 / 对比 / 拆解)放主语后,观众一眼知道这是什么类型。
- **简介**:可长。结构 = 2-3 段内容概述(含核心数字与诚实短板)→ 空行 → `章节:` 时间戳列表
  → 空行 → `#标签`。
- **章节时间戳**:第一条必须 `00:00`;每条从**最终导出字幕**核对,格式 `MM:SS 章节名`;
  8-10 条为宜,章节名用观众语言不用内部黑话。
- 拿不准的标题:后台「标题测试(Test & compare)」同时挂 3 条,让数据选。

## B站(主)

- **标题 ≤25 字**(官方手册硬上限,显示才完整)。结构 = 类型词 + 事件 + 亮点,至少 3 项。
  教程体裁才用「保姆级 / N 分钟 / 附文档」;观察 / 实测体裁用「实测 / 对比 / 翻车」。
  同赛道非教程高播放样本:「我完全由 Claude Code 编写的代码,运行情况如何?」83 万、「测了 GLM5 配合 Agent Teams,我有点 emo 了」7 万。
- **简介**:比 YouTube 短,2-3 句讲清这期干什么 + 一句诚实短板;结尾固定带三连引导
  (「觉得有用的话,三连是对我最大的支持」);分段进度可复用 YouTube 章节戳(放置顶评论)。

## 抖音(主)

- **首行 ≤20 字,就是那句判决**(逻辑 + 情绪各占一半:数字管逻辑,「全部中招 / 演都不演了」管情绪);
  第二行 1-2 句展开;**末尾堆标签**(4-6 个,主题词 + 工具词 + 泛词混搭)。
- 抖音信息流自动播放,**点击靠封面和前 3 秒,标题管停留和搜索**——杠杆在封面文字和首帧,标题首行和封面文字说同一个判决。
- 版面小,诚实短板不必塞;判决用可核验的数字说,程度词留给数字。

## 视频号(分发)

- 微信生态,**干净、少标签**:1 句判决 ≤25 字 + 核心数字即可,最多带 1 个标签或不带。

## 小红书(分发)

- **标题 ≤20 字**(硬限制,交付前数一遍),同一句判决压短。
- **正文**:emoji 分点种草风(✅/🔁/⚠️/📌),3-5 个点;必带一条诚实点(可信度);
  收藏引导(「记得收藏慢慢看」);末尾 4-6 个标签。

## TikTok(分发)

- 默认英文(国际向),**≤50 字符**,同一结构(Tool + verdict + number);**视频是中文音轨时先问用户投哪个受众**:
  华语区 → 直接复用抖音版;国际区 → 英文标题+简介,英文里保留精确数字,标签用 #AgentTeams #ClaudeCode 这类英文 tag。

## 常用标签池

`#ClaudeCode` `#AI自动化` `#效率工具` `#AI` + 当期主题词(中英各备一个)。
英文:`#AIAutomation` `#AIWorkflow` + 当期英文术语。
